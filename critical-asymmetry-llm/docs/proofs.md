# Preuves des Theoremes 1-4

## Theoreme 1 - Convergence a deux echelles
Sous H1-H5 et eta_psi / eta_theta -> 0, (theta_t, psi_t) converge
p.s. vers (theta*, psi*).

## Theoreme 2 - Convergence de A
Si R_A = -(A_hat - A*)^2, alors E[|A_hat - A*|] <= C1 exp(-lambda t) + C2 eta_psi.

## Theoreme 3 - Convergence globale
PPO + meta-politique convergent vers (theta*, psi*, A*).

## Theoreme 4 - Convergence multi-agents
Sous alpha > ||W||_2 + sigma^2, A_i -> A* p.s.
